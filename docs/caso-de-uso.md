# Diagrama de Caso de Uso

## Atores
- Usuário

## Casos de Uso
- Enviar mensagem
- Receber resposta do chatbot
- Solicitar atendimento humano

## Descrição
O usuário interage com o chatbot enviando mensagens. O sistema processa a mensagem e retorna uma resposta automática. Caso necessário, o usuário pode solicitar atendimento humano.
