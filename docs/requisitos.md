# Requisitos do Sistema

## 📌 Requisitos Funcionais

- RF01: O sistema deve permitir que o usuário envie mensagens ao chatbot.
- RF02: O chatbot deve responder perguntas frequentes (preço, serviços, horário, localização).
- RF03: O sistema deve identificar palavras-chave para gerar respostas adequadas.
- RF04: O chatbot deve informar quando não souber responder.
- RF05: O sistema deve permitir encaminhar o atendimento para um humano (simulado).

## ⚙️ Requisitos Não Funcionais

- RNF01: O sistema deve responder em até 2 segundos.
- RNF02: O sistema deve estar disponível 24/7.
- RNF03: O sistema deve ser escalável.
- RNF04: O sistema deve ter interface simples e intuitiva.
- RNF05: O sistema deve ser de baixo custo (preferencialmente gratuito).
